0.8.11 测试版更新

- 新增 一行命令安装：macOS 和 Linux 用 `curl -fsSL https://software.lynshen.org/cli/install.sh | bash`，Windows 用 `irm https://software.lynshen.org/cli/install.ps1 | iex`；也可以用 Homebrew：`brew install lynshen-team/tap/lynshen`
- 新增 终端界面重新设计：启动时显示 LynShen 标志，颜色自动适配深色和浅色终端（设了 NO_COLOR 就不用颜色），界面文字默认中文
- 新增 `/` 命令面板模糊匹配，每个命令带中文说明；切换模型、恢复会话、登录等面板可以直接打字筛选
- 优化 工具调用默认折叠，点击或按 ctrl+o 展开；改动显示行号，改了的字更醒目；失败的命令标红并显示退出码
- 优化 批准请求写清命令、目录和理由，按 1、2、3 直接选，esc 拒绝
- 优化 ctrl+c 先中断、再清空输入，空输入时连按两次才退出；↑↓ 翻看发过的消息，空输入框按 ? 查看全部快捷键
- 优化 手机上的今天用量能分开显示只对部分模型生效的限额（例如「Claude · 7 天」）
